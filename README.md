# Проект по АиСД

Сайт на FastAPI: свои структуры данных (хеш-таблица и дерево отрезков) поверх датасета MovieLens.

## Запуск

1. Положи файл `data.csv` (тот, что сохраняется в колабе) в папку `data/`.
2. Запусти:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Сайт откроется на http://127.0.0.1:8000
